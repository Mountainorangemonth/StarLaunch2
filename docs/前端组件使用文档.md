# StarLaunch 前端组件使用文档

本文档面向「前端可复用组件」，说明属性化组件的书写规范、每个组件的属性/事件/插槽与示例。

- 通用控件库：`frontend/src/components/ui/`（`Sl*` 前缀，纯展示、无业务）
- 页面级复用：`frontend/src/components/home/`（主页五个区块，由数据驱动）
- 配套静态数据：`frontend/src/data/`（默认文案，改文案只需改数据文件，组件与模板零改动）

> **一句话原则**：可复用组件一律「属性配置」。想要一个带提示文案和底部阴影的按钮，就写
> `<SlButton text="提示" shadow />`（等价于您示例中的 `<slbutton text="提示" shadow>`；
> SFC 模板中请使用规范写法 `<SlButton …>` 或 `<sl-button …>`）。

---

## 0. 书写规范

1. **组件命名**：通用控件一律 `Sl*` 前缀（StarLaunch 控件），置于 `components/ui/`；页面区块置于 `components/home/`。
2. **属性（props）**：模板中一律 **kebab-case**——`<SlButton text="提示" shadow variant="primary" />`；布尔类开关是「原子属性」（写了即 `true`，如 `shadow`、`disabled`）。
3. **双向值**：统一 `v-model`（`modelValue` / `update:modelValue`）。
4. **事件**：组件只 `emit` 语义事件（如 `click`、`close`、`action`），具体副作用由宿主页决定。
5. **class 保真**：组件根元素复用既有 `style.css` 类（`.btn`、`.card`、`.popover` …），外部传入的 `class` / `style`（如 `--d` 动画延时）自动合并到根元素。新增修饰类（如 `.is-shadow`）只增不改。
6. **文本外移**：区块文案来自 `src/data/*.js` 静态模块，经 props 传入；修改文案不碰组件。

## 1. SlButton — 按钮

属性化按钮，是多数小部件的入口示例。

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `text` | String | — | 按钮文案（与默认插槽二选一） |
| `icon` | String | — | sprite 图标名（如 `'i-play'`） |
| `variant` | String | `'primary'` | `primary` \| `ghost` \| `link` \| `icon`（映射 `.btn-primary`/`.btn-ghost`/`.link-btn`/`.icon-btn`） |
| `size` | String | `''` | `''` \| `'sm'` \| `'launch'`（映射 `.btn-sm`/`.btn-launch`） |
| `shadow` | Boolean | `false` | 底部强调投影（`.is-shadow`） |
| `block` | Boolean | `false` | 占满父宽居中（`.is-block`） |
| `fill` | Boolean | `false` | 图标实心（`.icon--fill`） |
| `disabled` | Boolean | `false` | 禁用 |
| `type` | String | `'button'` | 原生 `type` |

**事件**：`click`（内部已拦截原生冒泡，避免误触外层行/卡片的点击）。

**插槽**：默认插槽（有内容时优先于 `text`）。

```vue
<SlButton text="提示" shadow />                       <!-- 用户示例的规范写法 -->
<SlButton variant="primary" icon="i-play" fill text="启动游戏" size="launch" @click="launch()" />
<SlButton variant="ghost" icon="i-refresh" text="刷新索引" @click="refresh()" />
<SlButton variant="link" text="全部已读" @click="readAll()" />
<SlButton variant="icon" icon="i-more" aria-label="更多操作" @click="more()" />
```

## 2. SlIcon — 图标

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `name` | String | 必填 | sprite 中 `symbol` 的 id（`i-*`） |
| `size` | String | — | 显式宽高（如 `'18px'`），缺省继承 `.icon` 尺寸 |
| `fill` | Boolean | `false` | `.icon--fill` 实心 |

渲染 `<svg class="icon"><use :href="'#'+name" /></svg>`，外部 class/style 自动合并。

```vue
<SlIcon name="i-search" />
<SlIcon name="i-play" fill size="20px" />
```

## 3. SlCard — 玻璃卡片壳

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | String | — | 标题（`.head-title h2`） |
| `micro` | String | — | 眉标（`.micro`） |

**插槽**：默认插槽 = 卡片主体；`head`（整段标题区，覆盖 title/micro）；`headerAfter`（标题右侧工具区 `.head-actions`）。

```vue
<SlCard title="下载历史" micro="HISTORY" class="history-card" style="--d:.16s">
  <template #headerAfter><SlButton variant="link" text="清空记录" /></template>
  <div class="history-list">…</div>
</SlCard>
```

## 4. SlSwitch — 开关

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | Boolean | — | v-model 值 |
| `label` | String | — | 无障碍 `aria-label` |
| `sm` | Boolean | `false` | 小号 `.switch--sm` |
| `disabled` | Boolean | `false` | 禁用 |

```vue
<SlSwitch v-model="checkUpdate" label="启动前检查更新" />
<SlSwitch :model-value="app.performance" label="性能模式" @update:model-value="onPerf" />
```

## 5. SlRange — 范围滑杆

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | Number | — | v-model 值 |
| `min` / `max` / `step` | Number | `0`/`100`/`1` | 区间与步长 |
| `disabled` | Boolean | `false` | 禁用（复用 `.range:disabled` 样式） |

内部按当前值写 `--p` 填充进度；外部传 `class="range--sm"` 换小号。

```vue
<SlRange v-model="globalMem" :min="2" :max="32" :step="1" class="range--sm" />
```

## 6. SlSeg — 分段切换

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `items` | Array | 必填 | `[{ value, label }]` |
| `modelValue` | String \| Number | — | v-model，比对 `items[].value` |
| `ariaLabel` | String | — | 组无障碍名 |

```vue
<SlSeg v-model="store.category" :items="[{ value:'version', label:'游戏本体' }, …]" aria-label="下载分类" />
```

## 7. SlTag — 标签

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `label` | String | 必填 | 文案 |
| `tone` | String | — | `update` \| `maint` \| `security` \| `note`，映射 `.tag-*` |

```vue
<SlTag label="版本更新" tone="update" />
<SlTag label="通知" tone="note" />
```

## 8. SlPopover — 浮层壳

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `open` | Boolean | — | v-show 显隐 |

仅提供 `.popover` 外壳；定位/尺寸/角色由使用方通过外部 class 与自身逻辑完成（参考 `AccountPopover` 相对 `#railAvatar` 定位）。

```vue
<SlPopover :open="open" class="account-pop" role="menu" aria-label="账户菜单">…</SlPopover>
```

## 9. SlModal — 弹窗壳

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `open` | Boolean | — | 显隐 |
| `closable` | Boolean | `false` | 点击背景遮罩触发 `close` |

**事件**：`close`。内容（头部/进度/按钮行）由默认插槽自理，参考 `LaunchModal` 的结构：

```vue
<SlModal :open="pending" closable @close="pending = false">
  <div class="launch-head">…</div>
  <p class="launch-meta">…</p>
  <div class="launch-actions">…</div>
</SlModal>
```

## 10. SlEmpty — 空态

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `text` | String | `''` | 空态文案（默认插槽优先） |

```vue
<SlEmpty v-show="rows.length === 0" text="没有匹配的实例，换个关键词试试。" />
```

## 页面级组件（components/home/，数据驱动）

与通用控件不同，这些是「内容区块」。除文案可由数据 props 注入外，还暴露少量语义事件。数据默认值统一放 `src/data/`。

| 组件 | props | 事件 | 数据来源 |
| --- | --- | --- | --- |
| `HeroQuote` | `quotes`（`[[text,by],…]`） | — | `data/quotes.js` |
| `NoticeBoard` | `noticeList`（`[{time,tag:{label,tone},text,pinned,unread}]`）、`feature`（`{kicker,titleLines,date,route,aria}`）、`title`、`micro` | `read-all` | `data/notices.js` |
| `AccountCard` | `profile`（`name,id,tagPro,status,level,xp,xpNow,xpTotal,skins,lastLogin`） | `open-home` | `data/profile.js` |
| `SystemCard` | `system`（`sub,kpis[{html,label}],specs[{dt,dd}],java,status`） | `redetect`、`copy` | `data/system.js` |
| `WeekCard` | `playtime`（`total,unit,delta,summary,days[{w,h,title,today}]`） | — | `data/playtime.js` |
| `QuickGrid` | `actions`（`[{icon,label,notice}]`） | `action`(item) | `data/quick.js` |

```vue
<!-- 组合示例：QuickGrid 把操作项与其 toast 文案一起交给宿主页；新增操作 = 在数据文件加一项 -->
<QuickGrid :actions="QUICK_ACTIONS" @action="toast.push($event.notice)" />
```
```vue
<!-- HeaderCard 示例：NoticeBoard 的 feature 决定横幅点击目标路由（默认 /download） -->
<NoticeBoard :notice-list="NOTICES" :feature="NOTICE_FEATURE" @read-all="toast.push('全部公告已标记为已读', 'i-check')" />
```

> `SystemCard.kpis[].html` 为受信任的静态片段（保留 `<small>` 单位），仅在编辑 `data/system.js` 时修改，勿让外部输入进入该字段。

## 组合模式与新增组件模板

**组合**：通用控件不直接产生业务副作用——按钮/开关只发事件，卡片只提供外壳，宿主的 view（`views/*`）负责接线（toast / store 写入 / 路由跳转）。

**新增一个属性化组件**（模板）：

```vue
<script setup>
defineProps({ label: String, disabled: Boolean })
const emit = defineEmits(['change'])
</script>
<template>
  <div class="my-control" :class="{ 'is-disabled': disabled }">
    <span>{{ label }}</span>
    <slot />
    <button type="button" @click="emit('change', $event.target)">…</button>
  </div>
</template>
```

要点：props 用受控语义、事件用语义动作、class 全部对齐 `style.css`；写完后在本文补一节，并在 `views/*` 里用起来。
