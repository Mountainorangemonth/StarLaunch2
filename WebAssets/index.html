特别鸣谢

原版文件、加载器元数据和社区资源都不是我们自己的服务器，感谢这些公益服务的维护者。

  • BM BMCLAPI 镜像源 bangbang93 提供，原版 jar、assets、libraries 与 Forge / NeoForge / Fabric 元数据的国内镜像
  • MI MCIM 社区资源镜像 z0z0r4 维护，把 Modrinth 的接口和文件缓存在国内，「社区资源下载源」用的就是它（镜像下载不计入原作者的下载量）
  • MR Modrinth Mod、整合包、资源包与光影的开放接口，文件都带 SHA-1 校验值
  • FQ Fabric / Quilt 加载器的版本元数据与安装器，安装时按这里的清单拉取
  • FN MinecraftForge / NeoForge Forge 与 NeoForge 的 maven 仓库，加载器版本列表和安装器都从这里取
  • Wiki Minecraft Wiki 版本对照、加载器说明与中文译名的参考来源
  • MC Material Color Utilities 整页配色由 Google 的 Material Color Utilities 生成，主题色都出自它

本启动器与上述服务没有隶属关系；接口出问题时，可以先把「下载源」切到镜像再试。 想接自己维护的镜像，改 Services/Mirrors.cs 就够。

登录账户

登录后能用正版皮肤、进正版服务器；离线账户只在本机生效。

直接借用官方启动器的登录状态

在官方启动器里登录一次微软账号（进过一次游戏），再回这里点下面的按钮：启动器会读出官方启动器保存的令牌，校验通过就写进账号列表。

官方启动器不会把刷新令牌交出来，导入的令牌大约 24 小时过期：过期后回官方启动器重登一次，再导入一遍。想彻底免掉这一步，还是得注册一个自己的 Azure 应用 ID（见「微软账户」页）。

需要一个 Azure 应用 ID

内置的应用身份被环境变量 MS_CLIENT_ID 关掉、或者你把自己填的 ID 清空时才会走到这里。到 Microsoft Entra 管理中心「应用注册」新建应用：帐户类型选「任何组织目录中的帐户和个人 Microsoft 帐户」，清单里把 isFallbackPublicClient 改成 true（等价于「允许公共客户端流」），再把「应用程序(客户端) ID」填到下面。

已内置应用身份，直接登录即可
